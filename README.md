# بذرة | منصة الروضة

منصة تفاعلية لأطفال الروضة، فيها أربعة أقسام: الأشكال، والألوان، والأعداد، و«ارسم على الخط».

- شخصيتان مساعدتان: «رفرف» للبنات و«رائد» للأولاد.
- صفحة «إنجازي» لكل طفل، فيها النجوم والمراتب والشهادات.
- لوحة للمعلمة تُفتح برمز دخول، وفيها سجل الأطفال وتصنيف إنجازهم.
- صفحة روابط مهمة تضم أدلة وزارة التعليم التطبيقية لرياض الأطفال.

يُحفظ سجل الفصل في متصفح الجهاز المستخدم داخل الفصل.
